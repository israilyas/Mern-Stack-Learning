

# JavaScript Fundamentals - Notes

## 1. Arrays and Array Methods

- **forEach**: Runs a function once for each element of the array.
- **map**: Creates a new array by applying a function to every element.
- **filter**: Creates a new array by keeping only the elements that meet a specific condition.
- **find**: Returns the first element that matches a given condition.
- **indexOf**: Returns the index of the first occurrence of a specified value.

---

## 2. Objects

- Objects store key-value pairs inside curly braces `{}`.
- `Object.freeze(obj)`: Prevents modifications to the object properties.

---

## 3. Functions

- Functions are special objects with a `typeof` "function".
- Functions have a `length` property that represents the number of expected arguments.

---

## 4. Asynchronous JavaScript (Async JS)

- **Synchronous Code**: Executes line by line.
- **Asynchronous Code**: Moved to a side stack and runs after synchronous code is finished.
- `async` and `await`: Handle promises and make asynchronous code look synchronous.
- `fetch()`: Used to make network requests and returns a Promise.
- `blob.json()`: Converts the response into readable JSON format.
